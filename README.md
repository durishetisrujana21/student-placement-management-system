# Student Placement Management System

## Technologies Used

* Java
* Spring Boot
* MySQL
* JPA/Hibernate
* Maven
* Postman

## Features

* Student Management
* Company Management
* Application Management
* Application Status Tracking
* Dashboard Statistics
* Validation
* Exception Handling

## APIs

* Student CRUD
* Company CRUD
* Application CRUD
* Dashboard API

## Database Tables

* student
* company
* application

## Dashboard Statistics

* Total Students
* Total Companies
* Total Applications
* Selected Students
